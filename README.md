# Syncfusion&reg; Blazor DOCX Editor (Document Editor)

The Syncfusion<sup style="font-size:70%">&reg;</sup> [Blazor DOCX Editor](https://www.syncfusion.com/docx-editor-sdk/blazor-docx-editor?utm_source=github&utm_medium=github&utm_campaign=github-blazor-docx-editor-examples) (Document Editor) is a feature-rich, user-interactive component that enables creating, editing, viewing, and printing Word documents with advanced formatting, editing capabilities, and broad support for document import and export formats.

# Key Features

* [Opens](https://help.syncfusion.com/document-processing/word/word-processor/blazor/opening-a-document?utm_source=github&utm_medium=listing&utm_campaign=github-blazor-docx-editor-examples) the native `Syncfusion Document Text (*.sfdt)` format documents in the client-side.

* [Saves the documents](https://help.syncfusion.com/document-processing/word/word-processor/blazor/saving-document?utm_source=github&utm_medium=listing&utm_campaign=github-blazor-docx-editor-examples) in the client-side as `Syncfusion Document Text (*.sfdt)` and `Word document (*.docx)`.

* Supports document elements like text, [image](https://help.syncfusion.com/document-processing/word/word-processor/blazor/image?utm_source=github&utm_medium=listing&utm_campaign=github-blazor-docx-editor-examples), [table](https://help.syncfusion.com/document-processing/word/word-processor/blazor/table?utm_source=github&utm_medium=listing&utm_campaign=github-blazor-docx-editor-examples), fields, [bookmark](https://help.syncfusion.com/document-processing/word/word-processor/blazor/bookmark?utm_source=github&utm_medium=listing&utm_campaign=github-blazor-docx-editor-examples), [shapes](https://help.syncfusion.com/document-processing/word/word-processor/blazor/shapes?utm_source=github&utm_medium=listing&utm_campaign=github-blazor-docx-editor-examples), [section](https://help.syncfusion.com/document-processing/word/word-processor/blazor/section-format?utm_source=github&utm_medium=listing&utm_campaign=github-blazor-docx-editor-examples), [header and footer](https://help.syncfusion.com/document-processing/word/word-processor/blazor/header-footer?utm_source=github&utm_medium=listing&utm_campaign=github-blazor-docx-editor-examples).

* Supports the commonly used fields like [hyperlink](https://help.syncfusion.com/document-processing/word/word-processor/blazor/link?utm_source=github&utm_medium=listing&utm_campaign=github-blazor-docx-editor-examples), page number, page count, and table of contents.

* Supports formats like [text](https://help.syncfusion.com/document-processing/word/word-processor/blazor/text-format?utm_source=github&utm_medium=listing&utm_campaign=github-blazor-docx-editor-examples), [paragraph](https://help.syncfusion.com/document-processing/word/word-processor/blazor/paragraph-format?utm_source=github&utm_medium=listing&utm_campaign=github-blazor-docx-editor-examples), [bullets and numbering](https://help.syncfusion.com/document-processing/word/word-processor/blazor/list-format?utm_source=github&utm_medium=listing&utm_campaign=github-blazor-docx-editor-examples), [table](https://help.syncfusion.com/document-processing/word/word-processor/blazor/table-format?utm_source=github&utm_medium=listing&utm_campaign=github-blazor-docx-editor-examples) and [page settings](https://help.syncfusion.com/document-processing/word/word-processor/blazor/section-format?utm_source=github&utm_medium=listing&utm_campaign=github-blazor-docx-editor-examples).

* Provides support to create, edit, and apply [paragraph and character styles](https://help.syncfusion.com/document-processing/word/word-processor/blazor/styles?utm_source=github&utm_medium=listing&utm_campaign=github-blazor-docx-editor-examples).

* Provides support to [find and replace](https://help.syncfusion.com/document-processing/word/word-processor/blazor/find-and-replace?utm_source=github&utm_medium=listing&utm_campaign=github-blazor-docx-editor-examples) text within the document.

* Supports all the common editing and formatting operations along with [undo and redo](https://help.syncfusion.com/document-processing/word/word-processor/blazor/history?utm_source=github&utm_medium=listing&utm_campaign=github-blazor-docx-editor-examples).

* Provides support to [cut](https://help.syncfusion.com/document-processing/word/word-processor/blazor/clipboard#cut?utm_source=github&utm_medium=listing&utm_campaign=github-blazor-docx-editor-examples), [copy](https://help.syncfusion.com/document-processing/word/word-processor/blazor/clipboard#copy?utm_source=github&utm_medium=listing&utm_campaign=github-blazor-docx-editor-examples), and [paste](https://help.syncfusion.com/document-processing/word/word-processor/blazor/clipboard#paste?utm_source=github&utm_medium=listing&utm_campaign=github-blazor-docx-editor-examples) rich text contents within the component. Also allows pasting simple text to and from other applications.

* Provides support to insert, and edit [form fields](https://help.syncfusion.com/document-processing/word/word-processor/blazor/form-fields?utm_source=github&utm_medium=listing&utm_campaign=github-blazor-docx-editor-examples).

* Provides support to insert, and edit [comments](https://help.syncfusion.com/document-processing/word/word-processor/blazor/comments?utm_source=github&utm_medium=listing&utm_campaign=github-blazor-docx-editor-examples).

* Provides support to track the [inserted and deleted content](https://help.syncfusion.com/document-processing/word/word-processor/blazor/track-changes?utm_source=github&utm_medium=listing&utm_campaign=github-blazor-docx-editor-examples).

* Provides support to perform spell checking for any input text.

* Allows user interactions like zoom, scroll select contents through touch, mouse, and keyboard.

* Provides intuitive UI options like context menu, dialogs, and [navigation pane](https://help.syncfusion.com/document-processing/word/word-processor/blazor/find-and-replace#show-or-hide-navigation-pane?utm_source=github&utm_medium=listing&utm_campaign=github-blazor-docx-editor-examples).

* Localizes all the static text to any desired language.

* Allows to create a lightweight Word viewer using module injection to view and [prints](https://help.syncfusion.com/document-processing/word/word-processor/blazor/print?utm_source=github&utm_medium=listing&utm_campaign=github-blazor-docx-editor-examples) Word documents.
